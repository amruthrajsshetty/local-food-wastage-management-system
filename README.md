# local-food-wastage-management-system

An analytics-based web application built with Python, SQL, SQLite, Pandas, and Streamlit to analyze food wastage, identify surplus food, understand supply-demand gaps, and support efficient food redistribution.

## Project Overview

Food wastage is a major social and operational challenge. This project provides an analytics platform that helps identify available surplus food, understand food provider contribution patterns, and analyze supply-demand gaps.

The application uses data analysis and SQL queries to generate useful insights that can support better food redistribution and resource allocation.

## Objectives

- Analyze food wastage and availability patterns
- Identify surplus food that can be redistributed
- Analyze supply-demand gaps
- Understand food provider contribution patterns
- Support better resource allocation
- Present insights through an interactive Streamlit application

## SQL Analysis

The project uses SQL queries to analyze the food wastage dataset and identify:

- Available food quantities
- Provider contribution patterns
- Supply-demand gaps
- Food redistribution opportunities
- Category-wise food availability

## Dashboard

The Streamlit application provides interactive visualizations and analytical insights to help understand food wastage and redistribution patterns.

## Key Business Value

The analysis can help organizations and food redistribution platforms:

- Identify surplus food
- Improve resource allocation
- Reduce food wastage
- Connect available food with potential demand
- Make data-driven redistribution decisions
